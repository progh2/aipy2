수업·평가 연결

1단원과 2단원은 각 6차시의 필수 경로를 두고 확장 학습을 별도로 제공합니다. 수행① 평가 요소는 기능·이벤트 10점, 모듈 구조·코드 품질 5점, 저널 5점입니다. 웹 점수는 연습용이며 공식 성적이나 제출 기록을 대체하지 않습니다.

실행 환경

브라우저 Python은 Pyodide 0.27.7을 고정하여 사용합니다. 최초 실행에는 CDN 접속이 필요합니다. 다중 파일 실행은 가상 폴더에서 진행합니다. GUI는 코드 문법 확인과 웹 시뮬레이션을 제공하며 실제 동작은 PC에서 확인합니다.
