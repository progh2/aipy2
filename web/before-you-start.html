      Python 설치하기

      VS Code는 편집기일 뿐, 코드를 실제로 실행하는 것은 파이썬입니다. 파이썬을 먼저 설치합니다.

      Windows

      1. python.org/downloads에서 3.12 이상 버전을 내려받습니다.
      2. 설치 프로그램 첫 화면 맨 아래 Add python.exe to PATH에 반드시 체크합니다.
      3. Install Now를 누릅니다.
      4. 마지막 화면에 Disable path length limit 버튼이 보이면 눌러 줍니다.

      PATH 체크를 놓쳤다면

      설치 파일을 다시 실행 → Modify → 다음 → Add Python to environment variables에 체크하고 다시 설치하면 됩니다. 지우고 다시 깔 필요 없습니다.

      macOS

      python.org 설치 파일을 받아 그대로 설치하거나, Homebrew가 있다면 brew install python@3.12로 설치합니다. macOS에 원래 들어 있는 파이썬은 버전이 낮으니 새로 설치하세요.

      제대로 됐는지 확인

      Windows는 Win+R → cmd, macOS는 터미널을 열고 아래를 입력하세요. 버전 번호가 나오면 성공입니다.

      명령 프롬프트 / 터미널
      python --version
pip --version

      macOS에서 아무 반응이 없거나 버전이 2.x로 나오면 python3 --version으로 확인하세요.

      "'python'은(는) 내부 또는 외부 명령이 아닙니다"

      PATH 설정이 안 된 것입니다. 위의 Modify 방법으로 다시 설정한 뒤, 열려 있던 명령 프롬프트 창을 닫고 새로 여세요. 창을 새로 열지 않으면 변경이 반영되지 않습니다.

      2. Windows 설치 중 추가 작업 선택 화면에서 아래 항목에 체크하세요.

      3. macOS는 내려받은 앱을 응용 프로그램 폴더로 옮긴 뒤 실행합니다.

      07

      Git 설치하고 최초 설정하기

      Git은 코드의 변경 이력을 기록하는 프로그램이고, GitHub은 그 기록을 인터넷에 올려 두는 곳입니다. 둘은 다른 것입니다. Git을 설치하고, 내가 누구인지 알려 주는 최초 설정을 해야 첫 커밋을 만들 수 있습니다.

      1. 이미 깔려 있는지 먼저 확인

      터미널(Ctrl+`)이나 명령 프롬프트에서 확인합니다. 버전이 나오면 설치는 이미 끝난 것이니 2번은 건너뛰세요.

      터미널
      git --version
      이렇게 나오면 설치됨
      git version 2.47.1.windows.1

      2. 설치하기

      • Windows — git-scm.com/download/win에서 내려받아 설치합니다. 선택 항목이 아주 많이 나오는데 전부 기본값으로 두고 Next만 눌러도 됩니다.
      • macOS — 터미널에 git --version을 치면 설치 안내 창이 뜹니다. 또는 xcode-select --install을 실행하세요. Homebrew가 있다면 brew install git도 됩니다.

      설치 후에도 git을 못 찾는다면

      열려 있던 터미널과 VS Code를 완전히 닫고 다시 열어야 새 PATH가 반영됩니다. 그래도 안 되면 재부팅하세요.

      3. 지금 설정이 되어 있는지 확인

      Git의 전역 설정은 .gitconfig라는 파일 하나에 저장됩니다. 아래 명령으로 그 내용을 확인합니다.

      터미널
      git config --list --global

      이런 반응이면 아직 설정이 없는 것입니다

      • 아무것도 출력되지 않고 그냥 다음 줄로 넘어감
      • fatal: unable to read config file '...': No such file or directory
      • user.name과 user.email 두 줄이 목록에 없음

      셋 중 하나라면 4번으로 진행하세요.

      값 하나만 콕 집어 확인하려면 이렇게 씁니다. 설정이 없으면 아무것도 출력되지 않습니다.

      터미널
      git config --global user.name
git config --global user.email

      4. 최초 설정하기

      아래 두 줄이 반드시 필요한 설정입니다. 커밋 하나하나에 이 이름과 이메일이 기록으로 남습니다.

      터미널 — 따옴표 안을 자기 것으로 바꿔서 실행
      git config --global user.name "Gildong Hong"
git config --global user.email "gildong@e-mirim.hs.kr"

      이메일은 GitHub 계정과 같은 것으로

      다른 이메일로 커밋하면 GitHub에 올렸을 때 내 잔디밭에 기록이 남지 않습니다. 02단계에서 GitHub에 가입할 때 쓴 이메일을 그대로 넣으세요.

      이메일을 공개하기 싫다면 GitHub이 주는 비공개 주소를 쓸 수 있습니다. github.com/settings/emails에서 Keep my email addresses private를 켜면 12345678+아이디@users.noreply.github.com 형태의 주소가 나옵니다. 그 주소를 user.email에 넣으세요.

      core.quotepath false한글 파일 이름이 \355\225\234처럼 깨져 보이는 것을 막습니다.

def make_data(n):

def slow_contains(data, target):
    """리스트를 처음부터 끝까지 훑는다."""
    for item in data:
        if item == target:
            return True
    return False


def fast_contains(data_set, target):
    """집합에서 바로 찾는다."""
    return target in data_set


def main():
    data = make_data(200000)
    data_set = set(data)
    targets = make_data(300)

    found_slow = sum(slow_contains(data, t) for t in targets)
    found_fast = sum(fast_contains(data_set, t) for t in targets)
    print("느린 방법 결과:", found_slow)
    print("빠른 방법 결과:", found_fast)

      3. 터미널에서 서버 모델 쓰기

      4. VS Code에 붙이기 (Continue 확장)

      1. 확장 화면에서 Continue(Continue.continue)를 설치합니다.
      2. Ctrl+Shift+P → Continue: Open Config를 실행해 설정 파일을 엽니다.
      3. 아래 내용을 참고해 모델을 추가하고 저장합니다.

      models:
  - name: 학교 서버 코더
    provider: ollama

      "model": "qwen2.5-coder:7b",

      설정 파일 형식은 버전에 따라 다릅니다

      Continue는 config.json에서 config.yaml로 형식을 바꿔 왔습니다. 위 두 가지 중 지금 열린 파일과 같은 형식을 골라 쓰세요. 어느 쪽이든 필요한 값은 똑같습니다.

      • provider — ollama 고정
      • model — 2번에서 확인한 모델 이름
      • apiBase — 선생님께 받은 서버 주소

      확장의 모델 추가 화면(+ Add model)에서 Ollama를 고르고 주소를 넣는 방법도 있습니다. 파일 편집이 부담되면 그쪽이 더 쉽습니다.

      제대로 됐는지 확인

      Continue 채팅 창을 열고 모델 선택 목록에 학교 서버 코더가 보이면 됩니다. 파이썬에서 리스트와 튜플의 차이를 세 줄로 설명해 줘 정도를 물어보고 답이 오면 연결 성공입니다.
