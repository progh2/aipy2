BEFORE THE CODE

코드 전에 알아 두기

새 이름·속성이 코드에 나오기 전에 짧게 봅니다. 외우기보다 역할을 먼저 구별하세요.

shape(높이, 너비, 채널)

NumPy 이미지의 축 순서입니다. (2, 3, 3)은 행 2·열 3·채널 3입니다.

픽셀 수 / size높이×너비 · 높이×너비×채널

픽셀은 위치의 개수입니다. size는 채널 값을 모두 센 원소 수라서 컬러면 더 큽니다.

Pillow.size

(너비, 높이)입니다. OpenCV의 shape와 앞뒤가 반대이므로 나란히 적습니다.
