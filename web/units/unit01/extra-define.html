BEFORE THE CODE

코드 전에 알아 두기

새 이름·속성이 코드에 나오기 전에 짧게 봅니다. 외우기보다 역할을 먼저 구별하세요.

정의와 호출def circlearea(r): … / circlearea(3)

def는 이름만 준비합니다. 본문은 호출할 때 실행됩니다. 최상위 print는 import 순간에 실행됩니다.

최상위 실행문

if나 def 밖에 있는 줄입니다. 모듈을 처음 불러올 때 바로 실행됩니다.
