BEFORE THE CODE

코드 전에 알아 두기

새 이름·속성이 코드에 나오기 전에 짧게 봅니다. 외우기보다 역할을 먼저 구별하세요.

사람이 쓴 규칙len(password) >= 8

조건을 코드에 직접 적습니다. 비밀번호 길이처럼 기준이 분명하면 머신러닝이 필요 없습니다.

데이터에서 본 패턴spam_tokens = ["free", "winner"]

자주 나온 단어를 목록에 모은 뒤 새 메일에 적용합니다. 진짜 학습 알고리즘은 아니지만, “규칙을 쓰기보다 사례를 모은다”는 역할만 보여 줍니다.

규칙 기반

사람이 조건과 예외를 작성합니다. 모든 인공지능이 머신러닝인 것은 아닙니다.
