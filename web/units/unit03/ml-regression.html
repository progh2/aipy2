BEFORE THE CODE

코드 전에 알아 두기

새 이름·속성이 코드에 나오기 전에 짧게 봅니다. 외우기보다 역할을 먼저 구별하세요.

숫자 예측과 오차ŷ = 가중합 + 절편 · MAE / MSE / R²

잔차는 예측과 정답의 차이입니다. R²는 평균 예측 기준이라 음수가 될 수 있습니다.

단위

MAE는 원래 목표값 단위입니다. 숫자만 보지 말고 큰 오류 사례도 확인합니다.

더 알아보는 팁 · 역사·영상 (펼치기)

HISTORY / VIDEO

더 알아보는 팁

역사 한 줄

최소제곱 직선은 1800년대 초 가우스·르장드르가 정리했습니다. 머신러닝에서는 같은 식을 예측 모델로 씁니다.

영상

Linear Regression, Clearly Explained!!! (StatQuest) ↗

영어 공개 강의입니다. 직선으로 숫자를 예측하는 아이디어만 보면 됩니다. 학교 네트워크·연령 정책을 확인하세요.

회귀는 연속적인 목표값을 예측합니다. 선형 회귀는 특성들의 가중합과 절편으로 값을 예측합니다. 예측한 값과 실제 값의 차이를 잔차라고 부릅니다.

MAE는 절대 오차 평균, MSE는 제곱 오차 평균입니다. MSE는 큰 오차에 더 큰 벌점을 줍니다. R²는 평균 예측 기준과 비교한 값으로 음수가 될 수 있습니다. 한 지표의 숫자만 보지 말고 목표값의 단위와 오류 사례도 확인하세요.

예측 숫자와 정답의 차이를 잔차라고 합니다. MAE는 원래 단위, MSE는 큰 오차에 더 민감하고, R²는 평균 예측보다 나은지를 보므로 음수가 될 수 있습니다.
