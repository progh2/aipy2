주요 알고리즘 활용 · 분류

이름에 회귀가 들어 있어도 범주를 예측하는 모델이 있어요.

분류(Classification)는 주어진 데이터가 어떤 범주(클래스)에 속하는지를 예측합니다(예: 이메일 스팸 구분, 증상 데이터로 질병 유무 진단). 대표 알고리즘 네 가지가 있습니다.

K-최근접 이웃(K-NN)은 새로운 데이터가 들어왔을 때 가장 가까운 K개의 이웃 데이터를 찾아 이들이 속한 범주를 기준으로 분류합니다. 로지스틱 회귀는 선형 방정식으로 계산된 값을 확률로 변환해 데이터를 특정 범주에 분류합니다. 결정 트리는 데이터를 분할하는 규칙을 기준으로 트리 구조를 생성하며, 여러 결정 트리를 다수결로 종합한 것이 랜덤 포레스트입니다. 서포트 벡터 머신(SVM)은 데이터를 고차원 공간으로 변환한 뒤 두 범주를 가장 잘 구분하는 결정 경계(초평면)를 찾습니다. 이 중 K-최근접 이웃을 붓꽃(Iris) 데이터로 직접 실습해 봅니다. (교과서 103~104쪽)

붓꽃(Iris) 데이터 세트는 꽃잎(petal)·꽃받침(sepal)의 길이와 너비로 세 품종(Setosa, Versicolor, Virginica) 중 하나를 분류하는 대표적인 실습 데이터입니다. knn.py의 6~8행은 load_iris()로 데이터를 불러와 특징(X)과 목표 변수(y)를 만듭니다.

12행 train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)로 훈련·테스트 데이터를 나눕니다. 전처리 차시에서 배운 train_test_split이 여기서도 그대로 쓰이는 것을 확인하세요. 16~17행은 KNeighborsClassifier(n_neighbors=5)를 만들고 fit(X_train, y_train)으로 학습시키며, 19~20행은 predict(X_test)로 테스트 데이터의 품종을 예측합니다. 실행 결과와 해석은 다음 슬라이드에서 확인합니다. (교과서 104~105쪽)

붓꽃 150송이 중 105송이는 훈련, 45송이는 테스트로 나뉘었습니다. X는 sepal length·width, petal length·width 네 개의 특징이고, y는 품종을 0, 1, 2로 인코딩한 값입니다. KNeighborsClassifier(n_neighbors=5)는 가장 가까운 이웃 5개를 참조하여 예측합니다.

새로운 붓꽃이 주어지면 모델은 가장 유사한 5개의 훈련 샘플을 찾아 그중 가장 많은 품종 쪽으로 예측합니다. 예측 결과 [2 1 2 1 2]는 첫 번째 붓꽃을 ‘2번 품종(virginica)’, 두 번째를 ‘1번 품종(versicolor)’으로 예측했다는 의미입니다. (교과서 105~106쪽)

knn.py와 같은 분할에서 이웃 수 K(하이퍼파라미터)를 1~15로 바꿔 가며 실제 실행하면 성능이 달라집니다. K=1일 때 훈련 정확도는 1.000이지만 테스트 정확도는 0.933으로, 훈련 데이터를 통째로 외운 과대 적합의 전형적인 모습입니다. 교과서에서 쓴 K=5는 테스트 정확도 0.978로 이 실험에서 가장 높습니다.

하이퍼파라미터는 감이 아니라 이런 실험 그래프로 고릅니다 — Ⅲ-9차시의 GridSearchCV가 이 실험을 자동화한 것입니다. for k in range(1, 16): 반복문 하나만 얹으면 같은 실험을 할 수 있습니다.

꽃잎 길이·너비 두 특성만으로 결정 경계를 그려 보면, K=1일 때는 경계가 훈련 데이터 한 점 한 점에 민감하게 반응해 울퉁불퉁하고, K=15일 때는 경계가 매끈하고 단순해집니다.

이 그림·이 분할에서는 오히려 K=1의 테스트 점수가 더 높게 나왔습니다 — 한 번의 분할 점수만으로 성급하게 결론 내리면 안 되는 이유이며, 그래서 Ⅲ-8차시에서 배우는 교차 검증이 필요합니다.

교과서 104~105쪽 knn.py — K-최근접 이웃으로 붓꽃 분류

전체 scikit-learn 모델은 PC에서 실행합니다. 브라우저에서는 연결된 원리 실습으로 입력·계산·결과

따라 하기 · knn.py에서 K를 1, 5, 15로 바꿔 보기

  1. 104쪽 knn.py와 같은 분할(test_size=0.3, random_state=42, stratify=y)에서 K=1로 K-최근접 이웃을 학습시키고 훈련·테스트 정확도를 출력하세요.

    from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)

model = KNeighborsClassifier(n_neighbors=1)
model.fit(X_train, y_train)
print('훈련 정확도:', round(accuracy_score(y_train, model.predict(X_train)), 3))
print('테스트 정확도:', round(accuracy_score(y_test, model.predict(X_test)), 3))

    확인: 훈련 정확도: 1.0 / 테스트 정확도: 0.933 — 훈련 데이터를 통째로 외운 과대 적합의 모습입니다.

  2. 같은 코드에서 n_neighbors만 5로 바꿔 다시 실행하세요(교과서 기본값).

    model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)
print('훈련 정확도:', round(accuracy_score(y_train, model.predict(X_train)), 3))
print('테스트 정확도:', round(accuracy_score(y_test, model.predict(X_test)), 3))

    확인: 훈련 정확도: 0.971 / 테스트 정확도: 0.978 — 이 실험에서 가장 높은 테스트 정확도입니다.

  3. n_neighbors를 15로 바꿔 다시 실행하고, K가 커질수록 결정 경계가 어떻게 달라지는지(79쪽) 한 문장으로 설명하세요.

    model = KNeighborsClassifier(n_neighbors=15)
model.fit(X_train, y_train)
print('훈련 정확도:', round(accuracy_score(y_train, model.predict(X_train)), 3))
print('테스트 정확도:', round(accuracy_score(y_test, model.predict(X_test)), 3))

    확인: 훈련 정확도: 0.981 / 테스트 정확도: 0.956 — K=1보다 훈련 정확도는 오르지만 테스트 정확도는 오히려 낮습니다.
