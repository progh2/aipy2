분류기k-NN · 로지스틱 · 트리 · SVM

로지스틱 회귀는 분류입니다. 거리 기반 모델은 파이프라인 안에서 스케일을 배웁니다.

stratify

나눌 때 클래스 비율을 유지합니다. 붓꽃처럼 품종 수가 비슷해야 비교가 공정합니다.

역사 한 줄

k-NN은 1951년 Fix·Hodges의 이웃 규칙에서, 로지스틱 회귀는 통계의 범주 모형에서, SVM은 1995년 Vapnik 등에서 이어집니다.

영상

Hello World — Machine Learning Recipes #1 (Google for Developers) ↗

영어 공개 강의(약 7분)입니다. 과일을 분류하는 첫 모델만 보면 됩니다. 학교 네트워크·연령 정책을 확인하세요.

k-NN은 가까운 이웃들의 정답을 참고합니다. 로지스틱 회귀는 분류에 사용하는 모델이고, 결정 트리는 조건으로 데이터를 나누며, SVM은 범주 사이의 경계를 학습합니다.

붓꽃 예제에서 X는 꽃받침·꽃잎의 측정값이고 y는 품종입니다. stratify=y는 분할 시 클래스 비율을 고려합니다. k-NN·SVM 등은 거리나 스케일의 영향을 받으므로 전처리를 파이프라인 안에서 학습합니다.

로지스틱 회귀는 이름과 달리 분류에 씁니다. 웹 원리에서는 가까운 이웃의 표를 직접 세고, PC 예제에서 같은 분할로 네 모델을 비교합니다. 테스트 점수로 k를 고르지 마세요.
