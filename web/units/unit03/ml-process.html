BEFORE THE CODE

코드 전에 알아 두기

새 이름·속성이 코드에 나오기 전에 짧게 봅니다. 외우기보다 역할을 먼저 구별하세요.

나누는 순서문제·기준 → 분할 → 훈련에서만 전처리 → 검증 → 테스트

평가용 자료는 먼저 떼어 둡니다. 평균·스케일도 훈련 부분에서만 구합니다.

검증과 테스트

검증은 모델·설정을 고를 때, 테스트는 선택을 마친 뒤 한 번 보고할 때 씁니다.

역사 한 줄

훈련과 평가를 나누는 습관은 1990년대 이후 표준이 되었습니다. 전처리 값도 훈련 부분에서만 구해야 새 데이터 평가가 공정합니다.

영상

Machine Learning for Everybody – Full Course (freeCodeCamp) ↗

영어 공개 강의입니다. 목차의 train/test 분할 구간만 보면 됩니다. 나머지 긴 코스는 건너뛰어도 됩니다. 학교 네트워크·연령 정책을 확인하세요.

문제 정의 → 수집·탐색 → 전처리 → 모델 선택 → 학습·평가 → 해석·응용으로 진행합니다. 실제 프로젝트에서는 결과를 보고 앞 단계로 돌아가 수정하기도 합니다.

평가용 데이터는 먼저 분리해 둡니다. 평균·스케일·범주 목록처럼 데이터에서 배우는 전처리 값도 훈련 부분에서만 구합니다. 모델 후보는 검증 데이터나 교차 검증으로 비교하고, 최종 테스트는 선택을 마친 뒤 사용합니다.

성공 기준을 “평균 예측보다 MAE가 낮은가”처럼 숫자로 먼저 적으세요. 그다음 자료를 훈련·검증·테스트로 나누고, 전처리 값은 훈련 부분에서만 구합니다.

파이의 한 줄 힌트 · 아하!입력부터 결과까지, 한 단계씩 연결해 봐요.

먼저 흐름도에서 데이터가 바뀌는 곳을 찾고, 코드의 같은 부분을 바꾸어 결과를 비교하세요.
