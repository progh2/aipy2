BEFORE THE CODE

코드 전에 알아 두기

새 이름·속성이 코드에 나오기 전에 짧게 봅니다. 외우기보다 역할을 먼저 구별하세요.

양성을 먼저TP FP FN TN → 정확도·정밀도·재현율·F1

스팸을 양성으로 두면, 정상 메일을 스팸으로 보낸 것은 FP입니다. 불균형이면 정확도만 보지 않습니다.

임계값

확률을 양성으로 부를 기준입니다. 올리면 FP는 줄거나 같고 FN은 늘거나 같습니다.

역사 한 줄

혼동행렬은 의학·정보검색에서 쓰이던 오류 분류표입니다. 정밀도·재현율은 어떤 실수를 줄일지에 따라 고릅니다.

영상

Machine Learning Fundamentals: The Confusion Matrix (StatQuest) ↗

영어 공개 강의입니다. 실제와 예측을 표로 나누는 부분만 보면 됩니다. 학교 네트워크·연령 정책을 확인하세요.

양성으로 삼는 클래스를 먼저 정합니다. TP는 실제 양성을 양성으로, TN은 실제 음성을 음성으로 맞힌 수입니다. FP는 음성을 양성으로, FN은 양성을 음성으로 틀린 수입니다.

정확도는 전체 정답 비율입니다. 정밀도는 양성 예측 중 실제 양성의 비율, 재현율은 실제 양성 중 찾아낸 비율입니다. F1은 정밀도와 재현율의 조화평균입니다. 클래스 불균형이 있으면 정확도만으로 비교하기 어렵습니다.

양성이 무엇인지 먼저 정하고 TP·FP·FN·TN을 셉니다. 스팸을 양성이라 두면, 정상 메일을 스팸으로 보낸 것은 FP이므로 정밀도를 함께 봅니다. 불균형이면 정확도만으로 비교하지 않습니다.
