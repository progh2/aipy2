GUI 앱 개발 · 나만의 메모장 만들기

열기와 저장을 만드는 동안 1단원의 import와 함수가 다시 등장합니다.

텍스트 중심의 코드를 넘어서, 시각적인 인터페이스를 가진 앱을 만드는 과정은 매우 흥미롭고 실생활에도 유용하게 활용될 수 있습니다. 이 소단원에서는 파이썬의 tkinter 라이브러리를 활용하여 간단한 메모장 애플리케이션을 제작합니다.

사용자로부터 입력을 받아 저장하고, 저장된 파일을 다시 열어 내용을 확인할 수 있는 기능을 구현함으로써 GUI 구성 요소의 활용과 파일 입출력 기능을 종합적으로 이해할 수 있습니다. 전체 과정은 여덟 단계로 나누어 진행합니다.

1. 필요한 라이브러리 불러오기

import tkinter as tk
from tkinter import filedialog

tkinter는 GUI 구성에 필요한 기본 위젯을 제공하고, filedialog는 파일 열기 및 저장 대화 상자 기능을 제공합니다.

2. 메인 창 구성

window = tk.Tk()
window.title("나만의 메모장")

Tk()를 통해 GUI 창을 생성하고, title()로 제목을 설정합니다.

3. 텍스트 입력 영역 구성(45쪽 슬라이드에서 이어짐): text_area = tk.Text(window, wrap="word")로 여러 줄 입력 영역을 만들고, text_area.pack(expand=1, fill="both")로 창의 남는 공간을 모두 채우도록 배치합니다. wrap="word"는 단어 단위로 줄을 바꾼다는 뜻입니다.

4. 파일 열기 기능

def open_file():
    file_path = filedialog.askopenfilename()
    if file_path:
        with open(file_path, "r", encoding="utf-8") as file:
            text = file.read()
            text_area.delete("1.0", tk.END)
            text_area.insert(tk.END, text)

askopenfilename()을 통해 사용자가 파일을 선택할 수 있습니다. 선택된 파일을 열어 내용을 텍스트 영역에 삽입합니다. 사용자가 대화 상자를 취소하면 file_path가 빈 문자열이 되어 if file_path:가 거짓이 되므로 아무 일도 일어나지 않습니다.

5. 파일 저장 기능

def save_file():
    file_path = filedialog.asksaveasfilename(defaultextension=".txt")
    if file_path:
        with open(file_path, "w", encoding="utf-8") as file:
            file.write(text_area.get("1.0", tk.END))

asksaveasfilename()을 통해 저장할 위치를 설정하고, 텍스트 내용을 파일로 저장합니다.

6. 메뉴 구성

menu = tk.Menu(window)
window.config(menu=menu)

file_menu = tk.Menu(menu, tearoff=0)
menu.add_cascade(label="파일", menu=file_menu)
file_menu.add_command(label="열기", command=open_file)
file_menu.add_command(label="저장", command=save_file)
file_menu.add_command(label="종료", command=window.quit)

메뉴는 Menu 클래스를 통해 생성하며, 하위 항목을 추가하여 기능을 연결합니다. add_cascade는 상위 메뉴("파일")를 달고, add_command는 그 아래 항목을 만듭니다.

7. 프로그램 실행

window.mainloop()

mainloop()는 tkinter 이벤트 루프를 실행시켜 사용자 입력을 기다립니다. 이 줄이 있어야 창이 닫히지 않고 유지됩니다.

8. 전체 코드: 앞서 배운 내용을 기반으로 작성한 전체 코드의 앞부분(01~23행)입니다.

01  import tkinter as tk
02  from tkinter import filedialog
03
04  # 메모장 열기 기능 정의
05  def open_file():
06      file_path = filedialog.askopenfilename()
07      if file_path:
08          with open(file_path, "r", encoding="utf-8") as file:
09              content = file.read()
10              text_area.delete("1.0", tk.END)
11              text_area.insert(tk.END, content)
12
13  # 메모장 저장 기능 정의
14  def save_file():
15      file_path = filedialog.asksaveasfilename(defaultextension=".txt")
16      if file_path:
17          with open(file_path, "w", encoding="utf-8") as file:
18              file.write(text_area.get("1.0", tk.END))
19
20  # 윈도우 창 생성
21  window = tk.Tk()
22  window.title("나만의 메모장")
23  window.geometry("600x400")

01~02행은 라이브러리 임포트, 05~11행은 열기 기능, 14~18행은 저장 기능입니다. 함수는 정의만 되어 있고, 아직 호출되지 않습니다. 21~23행에서 창을 만들고 제목과 크기를 정합니다.

전체 코드의 나머지 부분(25~41행)입니다.

25  # 텍스트 입력창 생성
26  text_area = tk.Text(window, wrap="word")
27  text_area.pack(expand=1, fill="both")
28
29  # 메뉴 구성
30  menu_bar = tk.Menu(window)
31  window.config(menu=menu_bar)
32
33  file_menu = tk.Menu(menu_bar, tearoff=0)
34  menu_bar.add_cascade(label="파일", menu=file_menu)
35  file_menu.add_command(label="열기", command=open_file)
36  file_menu.add_command(label="저장", command=save_file)
37  file_menu.add_separator()
38  file_menu.add_command(label="종료", command=window.quit)
39
40  # GUI 실행
41  window.mainloop()

26~27행은 텍스트 입력창, 30~38행은 메뉴 구성입니다. 37행 add_separator()는 항목 사이에 구분선을 넣습니다. 41행 mainloop()가 실행되어야 비로소 창이 화면에 나타나고 클릭·입력을 받기 시작합니다.

탐구 활동(55쪽): IDLE의 macosx.py 코드에서 import tkinter, root = tkinter.Tk()가 들어갑니다. IDLE도 tkinter로 만들어진 GUI 애플리케이션입니다.

완성한 메모장을 실행하면서 다음을 확인하세요. 창 제목과 크기가 설정한 대로 보이는지, 텍스트 입력창에 자유롭게 글을 쓸 수 있는지, 파일 메뉴의 열기·저장이 실제로 동작하는지, 취소를 눌렀을 때 오류 없이 창이 그대로 유지되는지입니다.

메모장을 완성한 뒤 다섯 가지를 스스로 점검해 보세요. ① 입력: Text 위젯으로 여러 줄을 입력할 수 있는가. ② 이벤트: 메뉴 클릭이 open_file·save_file 함수를 정확히 호출하는가. ③ 배치: pack의 expand·fill로 창 크기에 맞게 입력창이 늘어나는가. ④ 파일: 열기·저장이 UTF-8로 올바르게 동작하고 취소 시 오류가 없는가. ⑤ 설명: 각 단계의 코드가 무슨 일을 하는지 내 말로 설명할 수 있는가.

교과서 메모장 여덟 단계로 따라 만들기

이 튜토리얼은 GUI 창을 엽니다. 웹 실습실에서는 실행되지 않으니 코드를 복사해 PC의 파이썬(IDLE 등)에서 실행하며 따라 하세요.

  1. ① 라이브러리 불러오기. tkinter와 파일 대화 상자를 담당하는 filedialog를 불러옵니다.

    import tkinter as tk
from tkinter import filedialog

    확인: 아직 화면에 보이는 것은 없습니다. 오류 없이 실행되면 다음 단계로 넘어가세요.

  2. ② 메인 창 구성. Tk()로 창을 만들고 title·geometry로 제목과 크기를 정합니다.

    import tkinter as tk
from tkinter import filedialog

window = tk.Tk()
window.title("나만의 메모장")
window.geometry("600x400")

window.mainloop()

    확인: "나만의 메모장" 제목의 600×400 크기 빈 창이 뜹니다.

  3. ③ 텍스트 입력 영역 구성. Text 위젯을 만들고 창을 가득 채우도록 배치합니다. mainloop() 앞에 추가합니다.

    text_area = tk.Text(window, wrap="word")
text_area.pack(expand=1, fill="both")

    확인: 창 안에 여러 줄을 쓸 수 있는 흰 입력 영역이 창 전체를 채웁니다.

  4. ④ 파일 열기 기능. 창을 만들기 전(라이브러리 불러오기 다음)에 open_file() 함수를 정의합니다.

    def open_file():
    file_path = filedialog.askopenfilename()
    if file_path:
        with open(file_path, "r", encoding="utf-8") as file:
            content = file.read()
            text_area.delete("1.0", tk.END)
            text_area.insert(tk.END, content)

    확인: 아직 실행 화면은 바뀌지 않습니다. 이 함수를 호출할 메뉴는 다음에 연결합니다.

  5. ⑤ 파일 저장 기능. open_file() 아래에 save_file() 함수를 이어서 정의합니다.

    def save_file():
    file_path = filedialog.asksaveasfilename(defaultextension=".txt")
    if file_path:
        with open(file_path, "w", encoding="utf-8") as file:
            file.write(text_area.get("1.0", tk.END))

    확인: 마찬가지로 아직 실행 화면은 바뀌지 않습니다.

  6. ⑥ 메뉴 구성. text_area.pack() 다음, mainloop() 앞에 메뉴를 추가합니다.

    menu_bar = tk.Menu(window)
window.config(menu=menu_bar)

file_menu = tk.Menu(menu_bar, tearoff=False)
menu_bar.add_cascade(label="파일", menu=file_menu)
file_menu.add_command(label="열기", command=open_file)
file_menu.add_command(label="저장", command=save_file)
file_menu.add_separator()
file_menu.add_command(label="종료", command=window.quit)

    확인: 창 위에 "파일" 메뉴가 생기고, 누르면 열기·저장·(구분선)·종료 항목이 보입니다.

  7. ⑦ 프로그램 실행. 메뉴의 "열기"로 텍스트 파일을 선택하면 내용이 입력창에 나타나고, "저장"을 누르면 입력한 내용이 파일로 저장됩니다. 대화 상자에서 취소해도 오류 없이 창이 그대로 유지됩니다.

    확인: 열기·저장·취소를 각각 시험해 오류 없이 동작하는지 확인합니다.

  8. ⑧ 전체 코드. 지금까지 만든 코드를 순서대로 모으면 교과서 54~55쪽의 완성 코드가 됩니다.

    import tkinter as tk
from tkinter import filedialog

# 메모장 열기 기능 정의
def open_file():
    file_path = filedialog.askopenfilename()
    if file_path:
        with open(file_path, "r", encoding="utf-8") as file:
            content = file.read()
            text_area.delete("1.0", tk.END)
            text_area.insert(tk.END, content)

# 메모장 저장 기능 정의
def save_file():
    file_path = filedialog.asksaveasfilename(defaultextension=".txt")
    if file_path:
        with open(file_path, "w", encoding="utf-8") as file:
            file.write(text_area.get("1.0", tk.END))

# 윈도우 창 생성
window = tk.Tk()
window.title("나만의 메모장")
window.geometry("600x400")

# 텍스트 입력창 생성
text_area = tk.Text(window, wrap="word")
text_area.pack(expand=1, fill="both")

# 메뉴 구성
menu_bar = tk.Menu(window)
window.config(menu=menu_bar)

file_menu = tk.Menu(menu_bar, tearoff=0)
menu_bar.add_cascade(label="파일", menu=file_menu)
file_menu.add_command(label="열기", command=open_file)
file_menu.add_command(label="저장", command=save_file)
file_menu.add_separator()
file_menu.add_command(label="종료", command=window.quit)

# GUI 실행
window.mainloop()

    확인: 메모장 앱이 정상적으로 실행되며, 열기·저장·종료가 모두 동작합니다. 이 코드는 practice 카드의 「교과서 메모장 · tkinter 전체 코드」 예제와 같습니다.
