pack·grid로 같은 폼 배치해 보기

이 튜토리얼은 GUI 창을 엽니다. 웹 실습실에서는 실행되지 않으니 코드를 복사해 PC의 파이썬(IDLE 등)에서 실행하며 따라 하세요.

  1. 이름·학번을 입력받는 폼을 pack()으로 위에서 아래로 배치합니다.

    import tkinter as tk

root = tk.Tk()
root.title("pack으로 배치하기")

tk.Label(root, text="이름").pack()
tk.Entry(root).pack()
tk.Label(root, text="학번").pack()
tk.Entry(root).pack()

root.mainloop()

    확인: 이름 라벨·입력창, 학번 라벨·입력창이 위에서 아래로 순서대로 나타납니다.

  2. 같은 폼을 grid()로 다시 만들어 비교합니다. 새 Frame을 만들고 그 안에 행·열로 배치합니다. mainloop() 앞에 추가합니다.

    grid_frame = tk.Frame(root)
grid_frame.pack(pady=10)
tk.Label(grid_frame, text="이름").grid(row=0, column=0)
tk.Entry(grid_frame).grid(row=0, column=1)
tk.Label(grid_frame, text="학번").grid(row=1, column=0)
tk.Entry(grid_frame).grid(row=1, column=1)

    확인: pack 폼 아래에 이름·학번 폼이 한 번 더 나타나는데, 이번에는 라벨과 입력창이 행·열로 나란히 정렬됩니다.

  3. 확인 버튼을 grid의 두 열에 걸쳐(columnspan) 넓게 배치합니다.

    confirm = tk.Button(grid_frame, text="확인")
confirm.grid(row=2, column=0, columnspan=2, sticky="ew", pady=6)

    확인: grid 폼 아래에 입력창 두 칸 너비만큼 넓은 "확인" 버튼이 보입니다.
