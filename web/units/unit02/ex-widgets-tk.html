BEFORE THE CODE

코드 전에 알아 두기

새 이름·속성이 코드에 나오기 전에 짧게 봅니다. 외우기보다 역할을 먼저 구별하세요.

Frameframe = tk.Frame(parent, padx=16, pady=16)

위젯을 묶는 상자입니다. 안쪽 여백(padx/pady)을 한곳에서 정할 수 있습니다.

Texttk.Text(parent, height=3)

여러 줄 입력입니다. Entry는 한 줄, Text는 여러 줄입니다.

BooleanVar / Checkbuttonchecked = tk.BooleanVar() tk.Checkbutton(parent, text=..., variable=checked)

체크 상태는 위젯이 아니라 변수에 저장됩니다. checked.get()이 True/False입니다.

StringVar / Radiobuttonchoice = tk.StringVar(value="A") tk.Radiobutton(..., variable=choice, value="A")

같은 variable을 쓰는 라디오는 하나만 선택됩니다. value가 서로 달라야 합니다.

Listboxlistbox.insert(tk.END, value)

목록에서 고릅니다. insert로 항목을 넣고, curselection()으로 고른 위치를 읽습니다.

Canvascanvas.create_oval(x1, y1, x2, y2, fill=...)

도형·그림을 그리는 공간입니다. 버튼·입력칸이 아니라 좌표로 그립니다.

pack을 빼면위젯.pack() # 생성만으로는 안 보임

도감의 위젯도 모두 pack을 호출합니다. 생성과 배치는 다른 단계입니다.

역사 한 줄

위젯(widget)은 window와 gadget을 붙인 말로, 창 안의 재사용 부품을 가리킵니다. Tk의 Label·Button·Entry가 바로 그 부품이고, 나중에 보는 Qt·wx·Kivy도 같은 역할을 다른 이름으로 제공합니다.
