메모장에서 배운 것으로 작은 도우미 앱 만들기

이 튜토리얼은 GUI 창을 엽니다. 웹 실습실에서는 실행되지 않으니 코드를 복사해 PC의 파이썬(IDLE 등)에서 실행하며 따라 하세요.

  1. 메모장과 같은 방식으로 새 창을 만들고, 오늘 할 일을 적을 Entry와 "추가" 버튼, 목록을 보여줄 Listbox를 준비합니다.

    import tkinter as tk

root = tk.Tk()
root.title("우리 반 할 일 도우미")

task_entry = tk.Entry(root)
task_entry.pack(fill="x", padx=10, pady=6)

task_list = tk.Listbox(root)
task_list.pack(fill="both", expand=True, padx=10, pady=6)

root.mainloop()

    확인: 할 일을 입력할 칸과 빈 목록 상자가 있는 창이 뜹니다.

  2. "추가" 버튼을 눌렀을 때 입력한 할 일을 목록에 넣고 입력칸을 비우는 함수를 연결합니다. Entry가 비어 있으면 추가하지 않도록 if로 막습니다.

    def add_task():
    text = task_entry.get().strip()
    if text:
        task_list.insert(tk.END, text)
        task_entry.delete(0, tk.END)

add_button = tk.Button(root, text="추가", command=add_task)
add_button.pack(pady=4)

    확인: 할 일을 쓰고 "추가"를 누르면 목록에 줄이 하나 늘고 입력칸이 비워집니다. 빈 채로 누르면 아무 일도 일어나지 않습니다.

  3. 목록에서 항목을 고른 뒤 "삭제" 버튼으로 지우는 기능을 더합니다. curselection()으로 선택한 위치를 읽습니다.

    def remove_task():
    selected = task_list.curselection()
    if selected:
        task_list.delete(selected[0])

remove_button = tk.Button(root, text="삭제", command=remove_task)
remove_button.pack(pady=4)

    확인: 목록에서 항목을 클릭해 고른 뒤 "삭제"를 누르면 그 항목이 목록에서 사라집니다.
