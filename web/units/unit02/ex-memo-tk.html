BEFORE THE CODE

코드 전에 알아 두기

새 이름·속성이 코드에 나오기 전에 짧게 봅니다. 외우기보다 역할을 먼저 구별하세요.

Menu / add_cascademenu = tk.Menu(window) window.config(menu=menu) menu.add_cascade(label="파일", menu=file_menu)

창 위쪽 메뉴 줄을 만듭니다. add_cascade는 "파일"처럼 펼쳐지는 상위 메뉴입니다.

add_commandfile_menu.add_command(label="열기", command=open_file)

메뉴 항목에 함수를 연결합니다. Button의 command와 같습니다. command=open_file()처럼 괄호를 붙이면 창을 열 때 대화 상자가 뜹니다.

tearoff=Falsetk.Menu(menu, tearoff=False)

메뉴를 창 밖으로 떼는 점선을 숨깁니다. 교과서 예제의 흔한 보완입니다.
