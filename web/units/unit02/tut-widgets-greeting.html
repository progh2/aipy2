입력한 이름을 Label에 인사로 띄우기

이 튜토리얼은 GUI 창을 엽니다. 웹 실습실에서는 실행되지 않으니 코드를 복사해 PC의 파이썬(IDLE 등)에서 실행하며 따라 하세요.

  1. 창을 만들고 이름을 입력할 Entry 위젯을 하나 붙입니다.

    import tkinter as tk

root = tk.Tk()
root.title("이름 인사")

name_entry = tk.Entry(root)
name_entry.pack(pady=10)

root.mainloop()

    확인: 빈 입력창 하나가 있는 작은 창이 뜹니다.

  2. 인사말을 보여 줄 Label을 Entry 아래에 추가합니다. mainloop() 앞에 두 줄을 더합니다.

    greeting = tk.Label(root, text="이름을 입력하세요")
greeting.pack(pady=10)

    확인: 입력창 아래에 "이름을 입력하세요"라는 글자가 보입니다.

  3. 버튼을 누르면 입력한 이름으로 인사말을 바꾸는 함수를 만들고, Button의 command에 연결합니다. 역시 mainloop() 앞에 추가합니다.

    def greet():
    name = name_entry.get()
    greeting.config(text=f"{name}님, 안녕하세요!")

greet_button = tk.Button(root, text="인사하기", command=greet)
greet_button.pack(pady=10)

    확인: 입력창에 이름을 쓰고 "인사하기" 버튼을 누르면 라벨의 문구가 "○○○님, 안녕하세요!"로 바뀝니다.

  4. 전체 코드를 확인합니다. command=greet처럼 함수 이름만 전달했는지(괄호를 붙이지 않았는지) 다시 확인하세요.

    import tkinter as tk

root = tk.Tk()
root.title("이름 인사")

name_entry = tk.Entry(root)
name_entry.pack(pady=10)

greeting = tk.Label(root, text="이름을 입력하세요")
greeting.pack(pady=10)

def greet():
    name = name_entry.get()
    greeting.config(text=f"{name}님, 안녕하세요!")

greet_button = tk.Button(root, text="인사하기", command=greet)
greet_button.pack(pady=10)

root.mainloop()

    확인: 이름을 바꿔 여러 번 눌러도 라벨 문구가 매번 새 이름으로 바뀝니다.
