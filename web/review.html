핵심 개념

핵심 개념

  • 모듈 임포트는 네 가지입니다. import 모듈(모듈명.함수()로 호출), from 모듈 import 함수(함수명만으로 호출), from 모듈 import *, import 모듈 as 새이름입니다.
  • as로 이름을 바꾸면 원래 모듈 이름으로는 접근할 수 없습니다(21쪽).
  • 패키지 안의 모듈도 import로 가져옵니다. 경로는 점(.)으로 구분합니다. 예: from nature.animals import bird
  • import 패키지.모듈 형식은 호출할 때마다 전체 경로를 써야 합니다. __init__.py의 __all__은 from 패키지 import * 로 가져올 모듈 목록을 정합니다.

tkinter의 구성 요소

교과서 50~51쪽

핵심 개념

  • tkinter는 Tk 객체, 위젯, 배치 관리자, 이벤트 처리의 네 가지 요소로 구성합니다.
  • Tk 객체(root = tk.Tk())는 프로그램의 기본 창이며 모든 위젯은 이 창 위에 생성됩니다.
  • 위젯은 Label, Button, Entry, Text, Checkbutton, Radiobutton, Listbox, Canvas, Frame 등입니다. 배치 관리자는 pack()(순차), grid()(행과 열), place()(좌표)입니다.
  • 이벤트 처리는 버튼 클릭 같은 동작에 반응하는 함수(callback)를 연결하는 것입니다. 예: Button(root, text="누르기", command=인사)

이벤트 처리 예 (51쪽)

event_demo.py

import tkinter as tk

root = tk.Tk()
def 인사():
    print("안녕하세요")
btn = tk.Button(root, text="누르기", command=인사)
btn.pack()

실행 결과 없음(창이나 파일이 필요한 코드입니다)

창을 띄워야 하는 코드라 실행 결과를 적지 않았습니다. 교과서 발췌에는 root.mainloop()가 없으므로 실제로 창을 유지하려면 마지막에 추가해야 합니다(54쪽).

헷갈리기 쉬운 점

  • GUI 창을 만드는 객체는 Tk()입니다. Entry(), Frame(), Label(), Button()은 창이 아니라 위젯입니다(51쪽 탐구 활동).
  • 위젯은 생성만 해서는 보이지 않습니다. pack(), grid(), place() 같은 배치 관리자로 위치를 정해야 합니다(51쪽).

def open_file():
    file_path = filedialog.askopenfilename()
    if file_path:
        with open(file_path, 'r', encoding='utf-8') as file:
            text = file.read()
        text_area.delete('1.0', tk.END)
        text_area.insert(tk.END, text)

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(iris.data, iris.target, test_size=0.3, random_state=42, stratify=iris.target)
knn_model = KNeighborsClassifier(n_neighbors=5)
knn_model.fit(X_train, y_train)
print(knn_model.predict(X_test)[:5])

이미지 전처리와 변환

교과서 163~172쪽

핵심 개념

  • 필터는 픽셀 값을 주변 픽셀과 결합해 새 값으로 바꾸는 연산입니다. 블러는 기본 블러(cv2.blur), 가우시안 블러(cv2.GaussianBlur), 중간값 블러(cv2.medianBlur)가 있고, 중간값 블러는 노이즈 제거와 경계선 보존에 유리합니다.
  • 에지는 밝기나 색이 급격히 변하는 경계이며 cv2.Canny(gray, 하위 임곗값, 상위 임곗값)로 검출합니다. 임곗값이 높을수록 강한 에지만 검출됩니다.
  • 이진화는 픽셀을 0 또는 255로 바꾸는 작업입니다. 고정 임곗값(균일한 조명), 오츠 자동 임곗값(명암 대비가 있는 이미지), 적응형 임곗값(조명이 불균일하거나 그림자가 있는 이미지)이 있습니다.
  • 기하학적 변환은 픽셀 좌표를 옮기는 것으로, 원근 변환은 cv2.getPerspectiveTransform()과 cv2.warpPerspective()로 기울어진 카드를 정면으로 펼칩니다. 마우스 클릭은 cv2.setMouseCallback()으로 연결합니다.

  • 이미지 전처리는 픽셀의 값(색, 밝기)을 다듬는 것이고, 기하학적 변환은 이미지의 위치나 형태(좌표)를 바꾸는 것입니다(168쪽).
  • 조명이 균일한 문서에는 고정 임곗값, 조명이 불균일한 환경에는 적응형 임곗값이 맞습니다. 오츠는 히스토그램을 분석해 최적값을 자동으로 계산합니다(167쪽).

  • 대표 특징은 에지(선), 코너(점), 윤곽선(폐곡선)입니다.
