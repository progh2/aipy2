# 파이 · 개발자를 꿈꾸는 여학생

- 제작 도구: 내장 image_gen. CLI 미사용.
- 사용자의 요청에 따라 치비 스타일 여학생으로 교체했습니다.
- 갈색 단발, 민트 머리핀, 네이비 코딩 후드, 청바지, 흰 운동화가 공통 특징입니다.
- 원본: pai-{welcome,thinking,idea,debug,celebrate}-v1.png. 기존 파일명으로 교체했습니다.
- PNG는 생성 원본, WebP는 같은 크기의 압축본입니다. 흰 배경입니다.

Preserve palette and illustration quality from reference, but subject must be entirely a human girl. Readable as a small educational website mascot.
