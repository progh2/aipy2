# 파이(Pai) · 과목 대표 캐릭터 제작 기록

- 제작: built-in `image_gen` 도구. CLI/API fallback은 사용하지 않았습니다.
- 캐릭터: 금빛 아기 비단뱀, 네이비 후드, 민트 끈, 말린 꼬리.
- 표정: welcome / thinking / idea / debug / celebrate.
- 최종 배경: 불투명 흰색. 첫 출력의 체크무늬 배경은 채택하지 않고 도구로 수정했습니다.
- PNG는 생성 원본, WebP는 같은 크기의 웹 표시용 압축본입니다. 원본 PNG는 그대로 보존했습니다.
- HTML에 별도로 작성한 대사로 학습 개념을 안내합니다. 교과서 원문 등장인물이 아닌 수업용 창작 캐릭터입니다.

## welcome-design

```text
Use case: stylized-concept.
Asset type: official course mascot sticker for a Korean high-school Python programming learning website.
Primary request: design one original extremely cute chibi baby PYTHON SNAKE learning companion, expressive, charming, approachable to teenage students. A SINGLE character, full body, not a sheet. Oversized rounded head, small softly curled snake tail/body, two tiny mitten-like cartoon arms, NO legs, no horns, no ears, no wings. Soft cream face, warm golden-yellow crown and small golden patches, cream belly, enormous expressive dark navy eyes with bright highlights and blush cheeks. Wears a small dark navy coding hoodie (hood DOWN) with mint-teal drawstrings and one simple golden rounded-square pocket patch with a tiny white angle-bracket mark, not text. Silky flat digital illustration with clean dark-navy outlines, gentle cel shading, warm friendly colors matching a navy/gold/mint educational website. Consistent distinctive silhouette, premium Korean chibi sticker illustration rather than 3D rendering.
Pose and expression: delighted welcoming smile, one tiny arm raised waving, other arm resting near hoodie pocket, curled tail visible, joyful open eyes and raised eyebrows. A few tiny golden sparkles close to its head.
Composition: square 1024x1024, single mascot centered, fills about 80 percent of canvas with comfortable margin around entire silhouette. All features and hand stay within frame. Readable at small size.
Background: genuinely transparent alpha, no white rectangle, no checkerboard pattern, no ground plane or cast shadow.
No words, no letters, no captions, no watermark, no other character, no Python logo imitation. This original baby python mascot will be called '파이' in HTML outside the artwork.
```
