# 인공지능 파이썬 실무 실습실

미림마이스터고등학교 2학년 **인공지능 파이썬 실무** 과목의 수업용 학습 사이트입니다.
교과서를 읽고 끝내는 대신, 같은 화면에서 코드를 바꿔 실행하고 문제를 풀며 확인합니다.

**학생용 주소: https://progh2.github.io/aipy2/**

멘토르 「인공지능 파이썬 실무」 교과서 전 범위(4단원)를 웹 학습으로 재구성했습니다.

| Ⅱ GUI 프로그래밍 | 9개 | tkinter로 원리 익히고 같은 앱을 PySide6로 확장, 메모장 만들기 |

- **학습 친구 '파이'** — 학습 단계마다 표정이 다른 대표 캐릭터가 지금 할 일을 안내합니다

## 어떻게 만들어져 있나

정적 사이트입니다. 서버가 없고 GitHub Pages가 `web/` 폴더를 그대로 서비스합니다.

```
tools/web/     ← 사람이 고치는 원본. 레슨·예제·문제·도식이 Python 데이터로 들어 있습니다
web/           ← 생성된 결과물. 이 폴더가 그대로 배포됩니다
firebase/      ← 학교 계정 로그인·권한 규칙과 콘솔 설정 절차
docs/          ← 제품 요구사항 문서(PRD)
```

`web/`의 HTML은 **생성물이므로 직접 고치지 않습니다.** `tools/web/`을 고치고 다시 생성하세요.
예외는 준비 안내 페이지 `web/before-you-start.html` 하나로, 이 파일만 직접 관리합니다.

```bash
python tools/web/build.py     # 생성
python tools/web/verify.py    # 검증
python -m http.server 8000 --directory web
```

`http://localhost:8000`으로 접속합니다. `file://`로 직접 열면 학습 데이터와 Worker가 동작하지 않습니다.
Windows에서는 UTF-8 모드가 필요합니다: `set PYTHONUTF8=1`

`main`에 푸시하면 [GitHub Actions](.github/workflows/pages.yml)가 생성·검증을 거쳐 자동 배포합니다.
검증은 모든 예제의 문법과 실제 실행, 정답 통과와 미완성 코드 실패, 문항 수, 내부 링크와 앵커, ZIP 무결성을 확인합니다.

## 계정과 수업 관리

학생은 학교 Google 계정(`@e-mirim.hs.kr`)으로 로그인하고, 반·번호는 교사가 미리 등록한 명단에서 가져옵니다.
서버 비밀을 둘 수 없는 정적 호스팅이므로 모든 권한 판단은 Firestore 규칙이 담당합니다.

- 설정 절차와 보안 근거: [firebase/README.md](firebase/README.md)
- 권한 규칙: [firebase/firestore.rules](firebase/firestore.rules)
- 교사용 명단 관리: [web/teacher/admin.html](web/teacher/admin.html) — CSV 일괄 등록·검사·내보내기, 미배정 학생 확인
- 교사 반 선택: 관리 화면 상단에서 **지금 수업하는 반**을 고르며, 반 ID는 `{학년}-{반}`(예: `2-3`)입니다. 명단·이후 보드·세션이 이 반만 봅니다.
- 수업 따라가기: [web/teacher/session.html](web/teacher/session.html) — 반 세션 시작·초점·시선 모으기. 학생은 자기 반만 따라옵니다.
  활성 세션이 있으면 교사가 학생용 단원 페이지에서 주제를 눌러도 같은 초점이 갱신됩니다.
- 학습 기록 동기화: 로그인하면 브라우저 기록을 `students/{uid}/state/current`에 맞추고, 교사 보드용 `progress/{uid}` 요약을 함께 씁니다. 로그인하지 않아도 학습은 그대로입니다.
- 앞으로 만들 기능(이해도 신호, 참여 현황 보드, 과제 제출): [docs/PRD.md](docs/PRD.md)

로그인은 학습의 전제가 아닙니다. 설정이 비어 있거나 네트워크가 끊겨도 사이트는 기존처럼 동작하고,
학습 기록은 브라우저에 남습니다.

## 범위에 관한 안내

- 원본 교과서 PDF와 평가 문서는 이 저장소에 포함하지 않습니다.
- 공개 정적 사이트이므로 정답을 열람할 수 있습니다. 공식 시험 보안이나 성적 관리 도구가 아닙니다.
- GUI와 OS 셸·pip 예제는 PC 실습용으로 표시하며, 웹에서는 문법 확인과 학습용 시뮬레이션만 제공합니다.
- 카메라·개인 사진·YOLO 가중치는 PC에서 준비하며 자동으로 켜거나 업로드하지 않습니다.
